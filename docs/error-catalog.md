# Uncertain Error Catalog

This catalog documents the structured diagnostics emitted by the `uncertain` compiler and type checker.
Every diagnostic pinpoints the location of the issue. Run `uncertain --explain <code>` for the same
explanations on the command line.

_This file is generated by `scripts/gen_error_catalog.py`; edit that script (or `src/uncertain/diagnostics.py`) instead._

---

## `syntax-error` (error)

The source code could not be tokenized or parsed.

**Example:**
```calc
let a = sensor_read(;
```

**Diagnostic Output:**
```text
error: syntax error
  --> line 1:21
   |
 1 | let a = sensor_read(;
   |                     ^ could not parse this
   |
   = note: Unexpected token ';' at 1:21
```

## `type-mismatch` (error)

An explicit `Measured<...>` annotation (on a `let`/`var`, a function argument or a function return type) does not match the mean and standard deviation computed by the type checker.

**Example:**
```calc
let reading: Measured<Normal(10.0, 2.0)> = sensor_read();
```

**Diagnostic Output:**
```text
error: type annotation mismatch
  --> line 1:1
   |
 1 | let reading: Measured<Normal(10.0, 2.0)> = sensor_read();
   | ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^ inferred type does not match annotation
   |
   = note: `reading` is annotated as Normal(10, 2) (mean 10, stddev 2), but the inferred distribution has mean 10, stddev 1
```

## `math-domain-error` (error)

An operation is mathematically undefined or cannot be represented, such as dividing by a distribution with a zero mean, taking the log of a non-positive mean, a numeric overflow, or distribution parameters outside their valid range (e.g. `poisson_read(-1)`).

**Example:**
```calc
let a = sensor_read() - 15.0;
let b = sqrt(a);
```

**Diagnostic Output:**
```text
error: math domain error
  --> line 2:9
   |
 2 | let b = sqrt(a);
   |         ^^^^^^^ invalid operation
   |
   = note: cannot compute the square root of a distribution with a negative mean (-5.0)
```

## `approximation-warning` (warning)

A non-Normal distribution (Uniform, Poisson, ...) is used in a product, ratio, nonlinear function or `prob()` query. The formulas used are exact for Normal inputs, so the resulting mean/variance (or probability) is a moment-matching approximation.

**Example:**
```calc
let u = uniform_read();
let n = sensor_read();
let c = u * n;
```

**Diagnostic Output:**
```text
warning: approximation warning
  --> line 3:9
   |
 3 | let c = u * n;
   |         ^^^^^ result is approximate
   |
   = note: multiplication assumes Normal inputs; the result for a Uniform input is a moment-matching approximation
```

---

## `delta-method-warning` (warning)

Division, `log` and `sqrt` use a first-order Taylor (delta method) approximation. When the input's standard deviation is large compared to its mean (coefficient of variation > 0.3), the true distribution is far from the approximation.

**Example:**
```calc
let a = normal_read(1.0, 2.0);
let b = 10.0 / a;
```

**Diagnostic Output:**
```text
warning: delta method may be inaccurate
  --> line 2:9
   |
 2 | let b = 10.0 / a;
   |         ^^^^^^^^ large relative uncertainty
   |
   = note: division by an uncertain value uses a first-order approximation, which is unreliable here (stddev/|mean| = 2.00)
```

## `uncertain-branch` (error)

A condition (`if`, `while`, `for`, `filter`) or comparison depends on an uncertain value. Loops and branches are unrolled at compile time, so their conditions must be deterministic. Use `prob(x > y)` to compute the probability of an uncertain comparison instead.

**Example:**
```calc
let a = sensor_read();
var b = 0;
if (a > 5.0) {
    b = 1;
}
```

**Diagnostic Output:**
```text
error: uncertain branch
  --> line 3:5
   |
 3 | if (a > 5.0) {
   |     ^^^^^^^ condition is not deterministic
   |
   = note: cannot compare uncertain values with '>' at compile time; use prob(...) to get the probability instead
```

## `loop-limit` (error)

A `while` or `for` loop ran for more iterations than the unroll limit (default 1000, configurable with `--max-unroll`).

**Example:**
```calc
var i = 0;
while (i >= 0) {
    i = i + 1;
}
```

**Diagnostic Output:**
```text
error: loop iteration limit exceeded
  --> line 2:1
   |
 2 | while (i >= 0) {
   | ^^^^^^^^^^^^^^^^ loop did not terminate
   |
   = note: this while loop did not finish within 1000 iterations
```

## `recursion-limit` (error)

Function calls are evaluated during type checking. A call chain exceeded the maximum depth, usually because of unbounded recursion.

**Example:**
```calc
fn f(x) {
    return f(x);
}
let y = f(1);
```

**Diagnostic Output:**
```text
error: recursion limit exceeded
  --> line 2:12
   |
 2 |     return f(x);
   |            ^^^^ call nesting is too deep
   |
   = note: calls to 'f' nested more than 64 deep; recursion must stop after a bounded number of deterministic steps
```

## `invalid-operand` (error)

An operation was applied to a value of the wrong shape: arithmetic on an array or struct, indexing into a non-array, accessing a missing struct field, or an out-of-bounds index.

**Example:**
```calc
let readings = [sensor_read(), sensor_read()];
let total = readings + 1;
```

**Diagnostic Output:**
```text
error: invalid operand
  --> line 2:13
   |
 2 | let total = readings + 1;
   |             ^^^^^^^^ invalid value here
   |
   = note: expected a number or distribution, got an array of length 2
```

## `not-constant` (error)

Distribution parameters, exponents, covariances and array indices must be deterministic values (standard deviation 0), known at compile time.

**Example:**
```calc
let lam = sensor_read();
let p = poisson_read(lam);
```

**Diagnostic Output:**
```text
error: expected a constant
  --> line 2:22
   |
 2 | let p = poisson_read(lam);
   |                      ^^^ value is uncertain
   |
   = note: Poisson parameter 'lambda' must be deterministic, but it has stddev 1
```

**Example:**


**Diagnostic Output:**
```text

  --> line 4:9
   |
 4 | let z = f(1);
   |         ^^^^ return problem
   |

```

## `import-error` (error)

An `import` statement failed: the module file was not found, could not be parsed, contains errors, or is part of a circular import.

**Example:**
```calc
import constants as c;
let g = c.g;
```

**Diagnostic Output:**
```text
error: import failed
  --> line 1:1
   |
 1 | import constants as c;
   | ^^^^^^^^^^^^^^^^^^^^^ could not import module
   |
   = note: module 'constants' not found (looked for <dir>/constants.calc)
```
